# PLASTO

**Доступ к сервисам и диагностика сети — в одном приложении для Windows.**

PLASTO помогает настроить DPI-обход для YouTube и Discord, подключить Telegram-прокси, выбрать DNS и проверить стабильность интернета. Работает на Windows 10 и 11 x64.

[Скачать PLASTO](https://github.com/plastoorg/PLASTO/releases/latest) · [Сайт](https://plastoorg.github.io/PLASTO/) · [Исходный код](https://github.com/plastoorg/PLASTO) · [Сообщить о проблеме](https://github.com/plastoorg/PLASTO/issues)

### С чего начать

1. Скачайте `PLASTO.exe` на странице релизов.
2. Запустите приложение от имени администратора: права нужны для сетевого драйвера WinDivert.
3. Выберите нужные функции и запустите проверку соединения.

Доступность сервисов зависит от провайдера и настроек. Некоторые функции используют прокси. О работе приложения, проверке файла и возможной реакции антивируса рассказано в [README проекта](https://github.com/plastoorg/PLASTO#антивирусы-и-windivert).
